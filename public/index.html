DPP Service · OwnYourData
API GitHub

Digital Product Passports on open standards

OwnYourData operates this public instance of the DPP Service, an open-source implementation of the EN 18222:2026 lifecycle API with passport content following EN 18223:2026. Reading passports is public and needs no account.
